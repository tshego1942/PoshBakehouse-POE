## About The Project 
This website was built for PoshBakehouse, a bakery in Sandton, Johannesburg.
The site has 5 pages: Home, About, Products, Enquiry, and Contact. 
## Pages Included 
- 'index.html' - Homepage with hero section
- 'about.html' - About us, Mission, Vision, Team
- 'products.html' - Menu with prices
- 'enquiry.html' - Customer enquiry form
- 'contact.html' - Contact details + Google Maps
## How to View 
1. Download the project
2. Open 'index.html' in any browser
